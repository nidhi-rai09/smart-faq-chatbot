# 🤖 Smart FAQ Chatbot

An AI-powered college assistant built using Python, Streamlit, and Google Gemini AI. It answers predefined frequently asked questions and uses Gemini AI to answer questions beyond its FAQ database.

## 🚀 Features

- 📚 FAQ Database for predefined questions.
- 🤖 Google Gemini AI integration.
- 💬 Interactive chat interface.
- 🧠 Conversation history.
- 🧹 Clear Chat functionality.
- 💡 Quick-question buttons.
- 📌 Sidebar with available topics.
- ✨ Handles general questions and spelling mistakes.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/nidhi-rai09/smart-faq-chatbot.git
```

### 2. Open the project folder

```bash
cd smart-faq-chatbot
```

### 3. Install dependencies

```bash
pip install streamlit google-genai python-dotenv
```

### 4. Configure Gemini API Key

Create a `.env` file in the project folder.

Add:

```text
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own Gemini API key.

### 5. Run the application

```bash
streamlit run web_app.py
```

The chatbot will open in your browser.
